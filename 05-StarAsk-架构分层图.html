未决问题与最低风险证据

  1. 问事真实回答/扣费/追踪：用无敏感测试档案跑一次低风险问题。
  2. 权限撤回的派生失效：用测试好友授权后撤回。
  3. 照片/派生特征保留：由产品方提供脱敏数据流与删除证明。
  4. 失败/重试/退款：提供脱敏 failed run 和账本记录。

以上未完成前，模型、数据表、内部 Agent、质量指标均保持 【未知】。

阅读指南

自上而下：从 L1/L2 看用户入口，经过产品/Agent/工具，落到模型、数据、知识与治理，适合产品和交互读者。

自下而上：从 L9 的身份、隐私、可观测性出发，检查 L7 数据与 L6 模型如何支撑 L5–L3，最后验证 L2 是否给用户足够的授权、成本和错误反馈，适合架构与合规读者。
